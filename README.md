# Garant

Бесплатное веб-приложение: проверка земельного участка в Казахстане перед покупкой.
Интерфейс перенесён из прототипа (8 экранов, английский по умолчанию, переключатель EN/RU).

## Что внутри

| Часть | Файл | Что делает |
| --- | --- | --- |
| Сайт | `index.html`, `app.js`, `config.js` | Все экраны, карта, поиск, вход, отчёт, ИИ-чат |
| База данных | `supabase/setup.sql` | 9 таблиц, защита строк (RLS), реестр изъятия |
| Сервер | `supabase/functions/garant/index.ts` | Проверка рисков и ИИ-помощник |
| Тесты | `tests/` | 16 тестов сервера и тест всего сценария в браузере |

## Откуда данные

- **Карта и поиск адресов**: OpenStreetMap (карта OpenFreeMap, поиск Nominatim). Работает по всему Казахстану.
- **Объекты рядом с участком** (вода, стройки, планируемые дороги, ЛЭП, промзоны, железная дорога): OpenStreetMap, запрашиваются в момент проверки.
- **Реестр изъятия для госнужд**: 19 проектов и 193 адреса по Астане и Алматы из публикаций постановлений акиматов за 2026 год (Tengrinews, bes.media, Krisha.kz, Ratel.kz, Kursiv со ссылкой на «Вечернюю Астану»). У каждой записи есть ссылка на источник. Собрано 11.11.2026.
- **Чего нет**: официальных красных линий, генплана и зон затопления. Их не публикуют как открытые данные, поэтому отчёт прямо пишет «не проверено».

Адреса реестра извлечены из текста публикаций автоматически. Перед важным решением сверяйте адрес с источником по ссылке в отчёте.

## Запуск в открытый доступ (около 30 минут, всё бесплатно)

### Шаг 1. Supabase: база данных и вход

1. Откройте supabase.com, нажмите **Start your project** и войдите через GitHub.
2. **New project**: имя `garant`, придумайте пароль базы (сохраните его), регион выберите ближайший. Нажмите **Create new project** и подождите 1–2 минуты.
3. Слева откройте **SQL Editor** → **New query**. Скопируйте туда весь файл `supabase/setup.sql` и нажмите **Run**. Должно появиться «Success».
4. Слева **Authentication** → **Sign In / Providers** → **Email**. Выключите **Confirm email** и нажмите **Save**.
   Причина: бесплатная почта Supabase отправляет письма только владельцу проекта, поэтому обычные пользователи не получили бы письмо с подтверждением.

### Шаг 2. Groq: ключ для ИИ-помощника

1. Откройте console.groq.com и зарегистрируйтесь (карта не нужна).
2. **API Keys** → **Create API Key**. Скопируйте ключ (он показывается один раз).

### Шаг 3. Supabase: серверная функция

1. Слева **Edge Functions** → **Deploy a new function** → **Via Editor**.
2. Имя функции: `garant` (именно так, маленькими буквами).
3. Удалите код-пример и вставьте весь файл `supabase/functions/garant/index.ts`. Нажмите **Deploy function**.
4. Откройте функцию `garant` → вкладка с настройками (**Details** или **Settings**). Выключите **Verify JWT** и сохраните.
   Функция сама проверяет вход пользователя, а эта галочка мешает новым ключам Supabase.
5. **Edge Functions** → **Secrets** → добавьте секрет с именем `GROQ_API_KEY` и значением из шага 2.

### Шаг 4. Адрес и ключ проекта

1. В Supabase откройте **Project Settings** → **API Keys** (и **Data API** для адреса).
2. Скопируйте **Project URL** (вида `https://abcdefgh.supabase.co`) и публичный ключ (**publishable** или **anon**).
3. Вставьте их в файл `config.js` в кавычки `SUPABASE_URL` и `SUPABASE_KEY`.

Никогда не вставляйте в `config.js` ключ **secret** / **service_role** и ключ Groq.

### Шаг 5. GitHub Pages: сайт

1. На github.com создайте новый **публичный** репозиторий, например `garant-app`.
2. **Add file** → **Upload files**. Перетащите всё содержимое этой папки (вместе с папками `supabase` и `tests`) и нажмите **Commit changes**.
3. **Settings** → **Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/garant-app/`.

### Шаг 6. Адрес сайта в Supabase

**Authentication** → **URL Configuration** → в **Site URL** вставьте адрес сайта из шага 5 и сохраните.

### Шаг 7. Проверка

1. Откройте сайт. Должна появиться карта Казахстана.
2. Введите кадастровый номер `21-318-067-2166` и нажмите **Check plot**. Это участок из постановления акимата Астаны от 02.10.2026.
3. Выберите результат, нажмите **Create account**, зарегистрируйтесь.
4. Должен открыться отчёт с высоким риском «Cadastral number is on a seizure list».
   Поиск по адресу (`Кенесары 21, Астана`) тоже должен дать риск из реестра, если карта находит дом точно.
5. Откройте **Ask Garant AI** и задайте вопрос.
6. Нажмите **Watch this plot**: участок появится в **My plots**.
7. Проверьте ещё один город: `Абая 10, Караганда`. В отчёте будет строка, что списков изъятия для этого города нет.

## Если что-то не работает

| Что видно | Причина | Что сделать |
| --- | --- | --- |
| «Garant is not set up yet» | Пустой `config.js` | Шаг 4 |
| «No connection to the server» при открытии отчёта | Функция не развёрнута или включён Verify JWT | Шаг 3, пункты 3–4 |
| «The AI assistant is not connected yet» | Нет секрета `GROQ_API_KEY` или ключ неверный | Шаг 3, пункт 5 |
| «The AI is busy right now» | Кончился бесплатный лимит Groq | Подождать |
| После регистрации просит подтвердить e-mail | Не выключен Confirm email | Шаг 1, пункт 4 |
| «Map data did not load» в отчёте | Бесплатный сервер OpenStreetMap занят | Нажать **Check again** через пару минут |
| Сайт перестал открывать отчёты через неделю простоя | Supabase усыпил бесплатный проект | В панели Supabase нажать **Restore project** |

## Ограничения бесплатного варианта

- Supabase: 500 МБ базы; проект засыпает после 7 дней без активности.
- Groq: дневной лимит запросов; в приложении стоит лимит 20 вопросов в день на пользователя.
- Поиск адресов и данные карты идут через общие бесплатные серверы OpenStreetMap. Для учебного проекта этого хватает, для тысяч пользователей нужен свой сервер.
- «Forgot password?» заработает после подключения своего почтового сервера (SMTP) в Supabase; затем поставьте `EMAIL_ENABLED: true` в `config.js`.
- Уведомления показываются на сайте, на почту они не отправляются.

## Как добавить записи в реестр изъятия

В Supabase → **Table Editor**: сначала строка в `seizure_projects` (проект, документ, источник), затем адреса в `seizure_notices` с тем же `project_id`. Для нового города поставьте `has_registry = true` в таблице `cities`.

## Отличия от прототипа

Экраны и стили те же. Изменены только тексты, которые стали бы неправдой:
- вместо «Astana» везде Казахстан, вместо демо-участка реальные данные;
- вместо «мы напишем на почту» сказано «появится в уведомлениях»;
- убрана фраза про двухфакторную защиту в настройках;
- фильтры поиска: «Адреса и здания», «Улицы и районы» вместо зон Ж/ОД, которых нет в открытых данных;
- у аватара появилось меню с кнопкой «Выйти».
